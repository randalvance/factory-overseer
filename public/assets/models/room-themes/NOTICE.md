# Generated room-theme furnishings

The four GLBs in this directory are generated artwork and are **excluded
from Factory Overseer's MIT code licence**. They were generated through paid
Comfy Cloud calls, then cleaned, decimated and explicitly recolored for the
paper factory. Keep this notice and [provenance.json](provenance.json) with
the files, including when copying them to a host application's asset server.

| Runtime file | Mesh provider and model | Runtime triangles | Bytes |
| --- | --- | ---: | ---: |
| `lab-specimen-cabinet.glb` | Meshy 7.1 through Comfy Cloud | 1,960 | 224,484 |
| `foundry-press.glb` | Tripo P2 through Comfy Cloud | 1,960 | 224,288 |
| `factory-parts-organizer.glb` | Tripo P2 through Comfy Cloud | 1,959 | 224,432 |
| `fabrication-paper-cutter.glb` | Tripo P2 through Comfy Cloud | 1,958 | 223,164 |
| **Total** | | **7,837** | **896,368** |

Each runtime derivative has one opaque vertex-color material and no model
textures. Concept images were generated with Seedream 5.0 Pro
(`seedream-5-0-pro-260628`) from the approved paper-diorama reference. The
portable provenance record identifies each completed concept and mesh job,
its provider/model, source and runtime hashes, and the cleanup script and
settings hashes. The full source records, including a rejected Tripo pilot,
remain in the source repository; raw meshes and concept images are not part
of this runtime package.

## Recorded provider terms

The project recorded these terms during generation; it does not replace or
extend them:

- [Comfy terms](https://comfy.org/terms-of-service/).
- [BytePlus AI terms](https://docs.byteplus.com/zh-CN/docs/legal/AI-Services-terms) for the Seedream concepts.
- [Meshy terms](https://www.meshy.ai/terms-of-use) for the specimen cabinet mesh.
- [Tripo terms](https://www.tripo3d.ai/terms) for the other three meshes.

[Comfy documents commercial use](https://comfy.org/cloud). Meshy and Tripo
terms distinguish paid and free users; no public document checked for this
batch explicitly maps a paid Comfy call to either provider's paid-user
category. This project therefore does not grant an unrestricted
redistribution licence for these raw/generated GLBs. Confirm the applicable
distribution terms before publishing a general-purpose asset pack. Local
package construction and application preview do not assert an MIT sublicense
to generated artwork.
